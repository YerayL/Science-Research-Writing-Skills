# Writing Cheatsheet — Apply These When Revising

## Quick Audit: Does This Section Have All Required Components?

### Introduction — 4 required components
```
☐ 1. Establishes importance + background + general problem area
☐ 2. Maps previous/current research
☐ 3. Identifies gap / problem / motivation / hypothesis
☐ 4. Presents the paper (aims + methods + results) + happy words
```
**Fix**: Add any missing component. Component 3 can be implicit. Component 4 MUST be explicit.

### Methods — 6 possible components (select what applies)
```
☐ 1. Overview of methods ± restated aim ± source of materials
☐ 2. Details of methods (with justification, not just description)
☐ 3. Figure/table content described/discussed
☐ 4. Reference to methods in other studies (comparison/justification)
☐ 5. Background information in Present Simple
☐ 6. Issues or problems acknowledged
```

### Results — 4 required components
```
☐ 1. Revisits method + general statement + invites reader to view graphic
☐ 2. Specific key results + evaluative comments + comparisons + explanations
☐ 3. Problems/issues with results ± reasons (if applicable)
☐ 4. Possible implications + happy words
```
**Critical fix**: If any number appears without an evaluative comment ("43%" not "only 43%" or "as high as 43%"), add one.

### Discussion — 3 main components
```
☐ 1. Announces structure of the Discussion section
☐ 2. States achievement/contribution + revisits literature/gap/results/implications/limitations
☐ 3. Restates achievement/contribution/impact + applications
```
**Critical fix**: Achievement verb MUST match the Introduction's aim verb. Check now.

### Conclusion — 11 possible components (select what target articles use)
```
☐ What paper is about
☐ Achievement
☐ Background
☐ Gap/Aim
☐ Method
☐ Key results
☐ Implications
☐ Limitations
☐ Applications
☐ Knowledge advance
☐ Future directions
```

### Abstract — 3 required components
```
☐ 1. Significance + problem + what paper does + happy words
☐ 2. Method + results + implications + happy words
☐ 3. Mapping to knowledge + achievement + applications + happy words
```
**Critical fix**: Can this Abstract be understood by someone who never reads the full paper? If not, add missing context.

## Verb Tense: Quick Fix Guide

| If the sentence is about... | Use... | Example fix |
|---------------------------|--------|-------------|
| Established fact / permanent truth | Present Simple | "X **is** biodegradable" |
| What you/others did (specific event) | Past Simple | "We **measured**..." |
| Link past research to present | Present Perfect | "Recent studies **have shown**..." |
| What the paper/section/figure does | Present Simple | "This paper **presents**..." |
| Method steps | Past Simple | "Cells **were incubated**..." |
| Results (tentative) | Past Simple | "The yield **increased** by 15%" |
| Results (confident, permanent) | Present Simple | "X **is** linearly related to Y" |
| Achievement/contribution | Present Perfect or Simple | "We **have demonstrated**..." |

**Common tense errors to fix**:
- Describing your results in Present Simple when evidence is not definitive → use Past Simple
- Describing established facts in Past Simple → use Present Simple
- Switching tenses randomly within a paragraph → standardize

## Certainty Language: Match Verb to Evidence

For each claim, ask: "How strong is my evidence?" Then choose:

| Evidence Level | Verbs to Use | Example |
|---------------|-------------|---------|
| PROOF | demonstrate, prove, establish, confirm | "We **demonstrate** that X causes Y" |
| STRONG | show, indicate, reveal, find, determine | "Our results **show** that..." |
| MODERATE | suggest, imply, point to | "These data **suggest** that..." |
| WEAK/SPECULATIVE | may, might, could, possibly, appear to | "X **may** contribute to Y" |
| CORRELATION ONLY | be linked to, be associated with, correlate with | "X **is associated with** Y" |

**Common certainty errors to fix**:
- "X demonstrates Y" when evidence is correlational → downgrade to "X is associated with Y"
- "X may be linked to Y" when you proved causation → upgrade to "X causes Y"
- "X produced Y" (directional) when you only have correlation → use non-directional
- "X is linked to Y" when direction is unknown → correct; don't imply direction

## Sentence Linking: Quick Fixes

Read the first 3 words of every sentence. If consecutive sentences start with unrelated subjects, apply:

| Technique | How | Before → After |
|-----------|-----|----------------|
| This/These + noun | Add "This/These [key term]" | "TEM was used. **These images** revealed..." |
| Repetition | Repeat last sentence's key term | "...yielded the isomer. **The isomer** was then..." |
| Connector | Add logical connector | Add: However, Therefore, Furthermore, Consequently |
| Signal word | Flag what's coming | Add: "A key challenge is...", "An important question is..." |

## Pre-submission Top 10 Checklist

```
☐ 1. Achievement stated explicitly with the SAME verb as the Introduction aim?
☐ 2. Contribution/impact specific (not "this is important" but "this enables X by Y")?
☐ 3. Title keywords match actual keyword list used in the paper?
☐ 4. Abstract: can it stand alone? Would a reader understand it without the full paper?
☐ 5. Every sentence has an identifiable function for the reader?
☐ 6. Evaluative comments on ALL data points (search for naked numbers: "X%", "Y ± Z")?
☐ 7. Verb tenses correct for each claim's certainty level?
☐ 8. Citations placed at the exact point of relevance (not all dumped at sentence end)?
☐ 9. Subsections have helpful titles that match their content?
☐ 10. "So what?" anticipated and answered throughout the text?
```

## Happy Words — Inject at Key Positions

**Where they go**: Introduction Component 4, Results Component 2 & 4, Abstract (all 3 components), Discussion Components 2 & 3

**Words to use**: novel, first, robust, efficient, cost-effective, significant, key, important, enables, advances, opens up, demonstrates, establishes, provides evidence, reveals, substantially, markedly

**Check**: Search your text for happy words. Are they present at the key positions listed above? If not, add them — this is how the reader (and reviewer) perceives value.
